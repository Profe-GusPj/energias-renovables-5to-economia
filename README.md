# Energías renovables y desarrollo sustentable

Aplicación educativa interactiva para estudiantes de 5.º año de Economía del nivel secundario.

## Contenidos
- Conceptos y tipos de energías renovables.
- Economía, inversión, costo de oportunidad y externalidades.
- Oportunidades y desafíos para Argentina.
- Simulador económico hipotético de inversión solar.
- Cuestionario autocorregible.
- Proyecto integrador para la comunidad.

## Ejecutar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Publicar en Streamlit Community Cloud
1. Ingresar a https://share.streamlit.io/ y conectar GitHub.
2. Seleccionar el repositorio `Profe-GusPj/energias-renovables-5to-economia`.
3. Elegir la rama `main` y el archivo principal `app.py`.
4. Presionar **Deploy**.

Los valores del simulador son hipotéticos y tienen fines exclusivamente educativos.
